# Support

Resume Studio is a personal, local-first project. Support is best-effort.

## Before opening an issue

- Read the [README](README.md) setup and troubleshooting notes.
- Run `npm run verify` and include the failing command and output.
- Confirm `pdflatex` and `pdftotext` are on `PATH` (or `PDFLATEX_PATH` is set).
- For AI issues, confirm the local service is running on `127.0.0.1:8000` and check `http://127.0.0.1:8000/health`.

## Where to ask

- **Bug reports:** use the bug report issue template.
- **Feature requests:** use the feature request template.
- **Security or exposed personal data:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Do not paste real resume content, phone numbers, emails, portraits, or private PDFs into a public issue. Use synthetic examples.
