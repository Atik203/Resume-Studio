# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

Examples of behavior that helps this project:

- Being respectful, specific, and constructive in issues and reviews.
- Assuming good intent while discussing technical trade-offs.
- Respecting privacy: never posting another person's resume, contact details, photos, or private documents.
- Giving clear reproduction steps and accepting that a local-first tool deliberately declines cloud features.

Examples of unacceptable behavior:

- Harassment, insults, discriminatory language, or personal attacks.
- Publishing private data or credentials.
- Deliberately introducing telemetry, cloud dependencies, or content-destroying behavior against the project's stated principles.
- Sustained disruption of issues, reviews, or discussions.

## Scope

This applies in repository issues, pull requests, discussions, and other project spaces.

## Enforcement

Report concerns privately to the repository owner through GitHub. The owner may remove comments, close threads, or block participants when needed. Reports will be handled as confidentially as practical.
